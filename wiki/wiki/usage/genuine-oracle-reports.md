# Genuine Oracle reports

The submenu "Analyses / statistics" / "Genuine Oracle reports" of [Panorama](panorama.md):
Oracle's own AWR, ASH and Performance Hub reports, generated by the database and
merely delivered by Panorama.

## The entries

([Panorama's website on GitHub Pages](../sources/rammpeter-github-io.md), menu overview.) All are generated "by time period and
instance".

| Entry | Generated by | Role needed |
|---|---|---|
| Performance Hub | `DBMS_PERF.REPORT_PERFHUB` | `EM_EXPRESS_BASIC` or `DBA` |
| AWR report | `DBMS_WORKLOAD_REPOSITORY.AWR_REPORT_HTML` | `OEM_MONITOR` or `DBA` |
| AWR global report (RAC) | `…AWR_GLOBAL_REPORT_HTML` | `OEM_MONITOR` or `DBA` |
| ASH report | `…ASH_REPORT_HTML` | `OEM_MONITOR` or `DBA` |
| ASH global report (RAC) | `…ASH_GLOBAL_REPORT_HTML` | `OEM_MONITOR` or `DBA` |

The package calls and the `DBA` alternative come from the tooltips of the report
buttons in the code ([Panorama source repository](../sources/panorama-source-code.md), commit `e8993893`,
`app/views/dba_history/_show_*_report.html.erb`); the roles `OEM_MONITOR` (from
11.2.0.4) and `EM_EXPRESS_BASIC` are also in the grant table of the landing page
→ [Privileges for Panorama](panorama-privileges.md).

## Licence

The reports are Oracle's own evaluation of [AWR](awr.md) and [ASH](ash.md) and need the
**Diagnostics Pack**; [Pack licence filter](../development/pack-license-filter.md) treats the
`DBMS_WORKLOAD_REPOSITORY` report functions accordingly. **[Panorama Sampler](panorama-sampler.md)
is no substitute here**: the database generates these reports from its own
repository, not from the sampler's tables.

> Conclusion: this is the one place where Panorama shows nothing of its own. The
> entries exist so that someone who needs the familiar report — to hand it to
> Oracle Support, say, or to a colleague who reads AWR reports fluently — does
> not need a second tool or access to the database server.

## Contradictions

- **Which role for what.** The usage guide (1.1) says `OEM_MONITOR` is needed
  "to use Oracle's own ready-made AWR and ASH reports as well as the SQL
  Monitoring plug-in". The landing page and the code assign `OEM_MONITOR` to the
  AWR and ASH reports only and `EM_EXPRESS_BASIC` to the Performance Hub; for the
  SQL Monitor report neither names a role. Recorded as it stands; the code is
  the more specific evidence.
- **"As of DB Release 11.4"** in the guide against 11.2.0.4 on the landing page
  — see [Privileges for Panorama](panorama-privileges.md).
- **Menu name.** A 2019 blog post calls the submenu "Genuine Oracle AWR-reports"
  ([SQL Monitor](sql-monitor.md)); the generated overview of 2026-09-02 has "Genuine Oracle
  reports".
